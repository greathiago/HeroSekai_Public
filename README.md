# Hero Sekai RPG - Ficha Firecast RRPG

Plugin oficial da ficha de personagem para o sistema **Hero Sekai RPG** no Firecast (RRPG).

## Instalação e Atualização

1. Baixe o arquivo `HeroSekai.rpk`.
2. Dê um duplo-clique no arquivo baixado ou arraste-o para dentro do Firecast aberto.
3. O Firecast instalará o plugin automaticamente.
4. A ficha conta com verificação automática de atualizações ao ser aberta, além do botão **Atualizar Ficha** para verificação manual.
